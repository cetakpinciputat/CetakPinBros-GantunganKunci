# Website Advistama Printing — Cetak Pin, Bros & Gantungan Kunci

Website statis responsif, siap dipublikasikan melalui GitHub Pages.

## Isi
- `index.html` — struktur halaman dan konten
- `style.css` — desain responsif
- `script.js` — menu mobile dan tahun otomatis
- `assets/` — foto produk yang Anda kirim

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `website-cetak-pin`.
2. Upload seluruh isi folder ini (bukan hanya file ZIP).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses selesai; alamat website akan muncul di bagian GitHub Pages.
